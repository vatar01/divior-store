# Магазин Divior: как запустить на своём домене

В папке три файла:
- `index.html` — сам сайт;
- `firestore.rules` — правила базы данных: кто что может читать и менять;
- `firebase.json` — настройки для Firebase Hosting.

Пока в `index.html` не вставлены настройки Firebase, сайт работает в **демо-режиме**: всё хранится только в браузере. Так можно всё попробовать, но настоящим покупателям этот режим не подходит.

Шаги ниже удобнее делать с компьютера.

---

## Шаг 1. Создайте проект Firebase (бесплатно)

1. Откройте https://console.firebase.google.com и войдите через Google.
2. Нажмите **«Создать проект»** (Add project), введите название, например `kobalt-shop`. Google Analytics можно выключить.

## Шаг 2. Включите вход по почте и паролю

1. В меню слева: **Build → Authentication → Get started**.
2. На вкладке **Sign-in method** выберите **Email/Password**, включите и сохраните.

## Шаг 3. Создайте базу данных

1. **Build → Firestore Database → Create database**.
2. Регион: `europe-west` (ближе всего к Казахстану из бесплатных). Режим: **Production mode**.
3. Откройте вкладку **Rules**, удалите всё, что там написано, и вставьте содержимое файла `firestore.rules`. Нажмите **Publish**.

## Шаг 4. Получите настройки и вставьте их в сайт

1. Нажмите ⚙️ → **Project settings**, внизу в блоке **Your apps** нажмите значок `</>` (Web).
2. Введите любое название и нажмите **Register app**. Появится блок `firebaseConfig = { apiKey: "...", ... }`.
3. Откройте `index.html` в любом текстовом редакторе, найдите в начале `const FIREBASE_CONFIG={` и замените значения на свои.

Эти ключи не секретные: они и должны лежать в сайте. Данные защищают правила из шага 3.

Если не хотите править файл сами, пришлите мне блок `firebaseConfig`, и я вставлю его за вас.

## Шаг 5. Почта администратора

Сейчас администратор — `ryabovdima112@gmail.com`. Чтобы сменить её, поменяйте почту в **двух** местах:
- `index.html`: строка `const ADMIN_EMAIL=...`
- `firestore.rules`: строка `request.auth.token.email.lower() == '...'`

## Шаг 6. Выложите сайт в интернет

**Самый простой способ: Netlify Drop**
1. Откройте https://app.netlify.com/drop.
2. Перетащите туда папку с сайтом. Через минуту появится ссылка вида `что-то.netlify.app`.

**Или Firebase Hosting** (нужен компьютер с Node.js):
```
npm install -g firebase-tools
firebase login
firebase init hosting   (выберите свой проект, папку оставьте «.», на вопрос о перезаписи index.html ответьте No)
firebase deploy
```

## Шаг 7. Подключите свой домен

1. Купите домен, например в ps.kz или hoster.kz (для `.kz`) или в Namecheap.
2. В Netlify: **Domain settings → Add custom domain**. В Firebase Hosting: **Add custom domain**. Сервис покажет DNS-записи, их нужно добавить в настройках домена у регистратора.
3. **Важно:** в Firebase откройте **Authentication → Settings → Authorized domains** и добавьте свой домен (и адрес `*.netlify.app`, если сайт на Netlify). Без этого вход на сайте не будет работать.

## Шаг 8. Станьте администратором

1. Откройте сайт, нажмите **«Войти» → «Регистрация»** и зарегистрируйтесь с почтой администратора.
2. Подтвердите почту по ссылке из письма (если письма нет, проверьте папку «Спам»).
3. Нажмите «Войти», откройте аккаунт и нажмите **«Я подтвердил»**. Появится кнопка **«Админ-панель»**.
4. Каталог в базе пустой. В админ-панели нажмите **«Загрузить 14 примеров»** или сразу добавляйте свои товары.

## Что стоит знать

- **Оплата.** Покупатель выбирает способ оплаты, а заказ приходит вам в админ-панель. Чтобы деньги списывались онлайн, нужен договор с Kaspi (Kaspi Pay) или банком-эквайером. После этого их платёжную форму можно подключить к сайту.
- **Суммы заказа** считает браузер покупателя. Сверяйте сумму, когда звоните подтверждать заказ.
- **Бесплатного тарифа Firebase** (Spark) хватает небольшому магазину: 50 000 чтений и 20 000 записей в день.
- **Фото товаров** хранятся прямо в базе в сжатом виде (до 640 px). Для каталога на сотни товаров с фото позже лучше подключить Firebase Storage.

## Telegram-бот администратора

Бот присылает новые заказы с кнопками смены статуса и сообщения из чата сайта (на них можно отвечать прямо в Telegram), а также понимает команды /new, /orders, /chats, /stats.

Переменные окружения в Netlify (Project configuration → Environment variables):

| Переменная | Откуда взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | @BotFather → /newbot |
| `TELEGRAM_CHAT_ID` | @userinfobot (несколько ID — через запятую) |
| `FIREBASE_CLIENT_EMAIL` | Firebase → Project settings → Service accounts → Generate new private key → поле `client_email` |
| `FIREBASE_PRIVATE_KEY` | то же JSON-файл → поле `private_key` целиком (от `-----BEGIN` до `END PRIVATE KEY-----\n`) |

После добавления: Deploys → Trigger deploy, затем один раз откройте
`https://splendid-pothos-40c027.netlify.app/.netlify/functions/tgbot?setup=1`
и напишите боту /help.

Ключ сервисного аккаунта даёт полный доступ к базе — храните его только в Netlify и никому не пересылайте.

## Защита заказов, страницы товаров, аналитика, оплата Kaspi

**Как теперь оформляется заказ.** Браузер покупателя отправляет только список товаров и количество. Сервер (функция `order`) сам:
- проверяет, что покупатель вошёл в аккаунт;
- берёт цены и наличие из каталога и считает сумму (подделать её нельзя);
- отсекает ботов: скрытое поле-ловушка, форму нельзя отправить быстрее 3 секунд, лимиты — 5 заказов в час с аккаунта и 10 с одного IP;
- списывает остатки. При отмене заказа (в боте или админке) товар возвращается на остаток.

**Обязательно:** скопируйте новый `firestore.rules` в Firebase Console → Firestore Database → «Правила» → «Опубликовать». После этого создать заказ в обход сервера нельзя.

**Страницы товаров.** У каждого товара есть свой адрес: `/product/k123…`. На нём есть заголовок, описание, цена и характеристики, которые видят Google и Яндекс, а в WhatsApp и Telegram показывается красивое превью с фото. Быстрый просмотр в окне остался, в нём есть кнопка «Открыть страницу товара».
- Карта сайта: `/sitemap.xml`. Добавьте её в Яндекс Вебмастер (webmaster.yandex.ru) и Google Search Console (search.google.com/search-console).

**Аналитика.** Админ-панель → «Настройки» → номер счётчика Яндекс Метрики и/или ID Google Analytics (G-…). Ваши визиты как администратора не считаются. Цели в Метрике: `checkout` (начал оформление), `order` (заказ), плюс электронная коммерция.

**Оплата Kaspi.** Способ «Kaspi — счёт на ваш номер»: заказ приходит в бот со статусом «⏳ Ждёт оплаты». Выставите счёт покупателю в приложении Kaspi Pay («Удалённая оплата» на его номер), а после оплаты нажмите в боте «💳 Оплачен».
